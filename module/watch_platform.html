Portable synchronous process execution and stdout redirection.

C wrappers launch commands, forward user interrupts, and redirect raw fpm library output. An interrupt received while waiting for a command latches stop_requested; ordinary nonzero child exits do not. OS detection uses fpm_environment:get_os_type.

  • private function fpm_watch_execute(command, silent, interrupted, launch_error) result(status) bind(C, name="fpm_watch_execute"))

    C process wrapper returning child status or 127 for a launch/wait error.

    command is NUL-terminated. On Windows, silent selects inherited streams: 0 normal, 1 discard both outputs, 2 redirect stdout to stderr. POSIX ignores this mode because the Fortran wrapper appends shell redirections. interrupted reports handled user interrupts; launch_error holds the OS error code separately from ordinary child failure.
