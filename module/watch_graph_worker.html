Isolate fpm model construction in a short-lived worker process.

fpm owns resources that cannot all be released through its public model API. Each refresh therefore runs in the actual watcher executable and returns one validated TOML snapshot. A private workspace also contains fpm probe files; the parent removes the whole workspace after success, failure, or cancellation. Byte strings use hexadecimal encoding so native paths survive control bytes and invalid UTF-8 without relying on TOML string encoding.
