enable_features add_stats

Enable built-in watcher plugins from watch_opts_t%enabled_features.

Currently only stats is supported; it counts completed commands internally. Plugin names come from [extra.fpm-watch].features and --watch-feature, independently of fpm's build features. Unknown names produce a warning.
