Build watch lists from fpm's manifest, model, and target graph.

Build mode watches every model source. Run/test mode selects named executable source closures. Link-only sources are conservatively retained because fpm does not expose its linker graph independently of its pruning allocator. Sources, include candidates, manifests, and version files form one normalized path list. Optional dependency watching includes dependency paths under the build tree. Up to 64 run/test roots receive bitmasks for later affected-target selection.
