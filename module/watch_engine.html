Portable polling, watch-list refreshes, and synchronous command execution.

The engine debounces changes, maps source edits to run/test targets, and refreshes the graph after watched configuration edits or optional periodic rescans. Failed refreshes preserve the accepted watch list. Commands block polling; ordinary command failures do not terminate continuous watching.
