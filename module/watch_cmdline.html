Read argv tokens, parse option values, and serialize command arguments.

quote_arg always quotes the full token, including empty arguments. POSIX serialization uses single quotes; Windows uses double quotes and C-runtime backslash rules. Platform selection comes from watch_platform:is_windows unless a quoting caller supplies an explicit override.
