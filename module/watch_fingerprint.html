Stream complete file contents and compare watch-list snapshots.

Every byte contributes to the fingerprint. Missing, empty, and unreadable files have distinct states; nonempty content uses a 63-bit hash. Hash collisions are still possible, so fingerprints are change detectors, not content identities. File reads share a reusable buffer and are intended for serial use.
