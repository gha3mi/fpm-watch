Emit terminal text, JSON Lines, and logfmt using process-wide settings.

Structured records, including errors, use stdout; text errors use stderr. Each emitted record is flushed immediately and occupies one physical line. Field constructors serialize typed values as JSON; logfmt quotes array values. Structured strings escape controls and replace invalid UTF-8 bytes with U+FFFD.
